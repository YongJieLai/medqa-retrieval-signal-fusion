# 医学问答检索分配研究：知识侧 × 模型侧信号融合

> **当前研究主线**（见 [`EXPERIMENT_SUMMARY.md`](EXPERIMENT_SUMMARY.md)）：在专家级医学问答 MedXpertQA 上，系统排查「检索增益为负」的根因，并验证「知识侧 coverage × 模型侧 familiarity 信号正交互补」的核心命题。

## 核心结论速览

- **检索质量无关**：把 BM25（20 万篇）升级到 MedCPT 语义检索（173 万篇），检索相关性提升但准确率反降（锚定偏差）。
- **单一信号无用**：familiarity / coverage / 语义分数都无法预测「该不该检索」（corr≈0）。
- **信号正交但门控撞天花板**：coverage × familiarity 确实正交互补（并集兜错题 +17），但检索对「模型失明」的题净救能力仅 3 题。
- **方向收敛**：不是「更聪明的检索」，而是「干预方式的升级」。

完整实验链、数据、脚本见 [`EXPERIMENT_SUMMARY.md`](EXPERIMENT_SUMMARY.md) 与 [`docs/`](docs/)。

## 0. 一句话目标

一批医学选择题共享一个总量检索预算 `B` 时，用一个只依赖知识图谱（KG）与语料的「知识缺口估值器」，在答题前给每道题算一个连续分数 `coverage(q)`（"这道题缺多少知识、值多少"），再把有限预算跨题全局分配给最值得检索的题，目标是用尽量少的预算尽量多答对题。

## 1. 问题定义

### 1.1 输入
- 一批医学选择题：`{题干, 四个选项}`，共 N 道题
- 一个总量检索预算 `B`（"检索"这个动作的总可用次数 / 成本上限）

### 1.2 输出
- 每道题的投入决策：`闭卷` 或 `检索`
- 按决策执行后，得到各题的答题结果（正确率）

### 1.3 约束与假设
- **模型冻结**：不改模型、不训练、不微调
- **模型无关**：不读模型内部状态（logits、隐层、自评都算"模型侧"，本文不用）
- **答题前**：信号必须在答题之前算出，不能用到答案

## 2. 核心思想

现有方法判断"这道题值不值得检索"，几乎都靠**模型侧信号**（熵、置信度、自评）。这些信号有一个结构性盲区：**模型可以自信地答错**（罕见病题，凭错误参数化记忆给出低熵高置信），于是模型侧信号恰好判反。

本文改从**知识侧**判断：只看"这道题需要哪些概念、这些概念在 KG 和语料里有多稀有、是不是推理必经"，由此估计"这道题客观上缺多少知识"。

**定位边界（务必守住）**：
- 做的是**答题前、跨题、全局的预算分配**，输出**连续分数**
- **不是**"逐题二元检索触发"，也**不是**"答题中防幻觉"（后者是 QuCo-RAG / Marina 的位置）
- 主叙事是"**知识侧信号与模型侧信号互补（融合 > 单独）**"，不是"客观信号全面碾压主观信号"

## 3. 方法概览（四步）

| 步骤 | 名称 | 说明 | 是否本文贡献 |
| --- | --- | --- | --- |
| 1 | 模型侧筛选 | 熵/置信度门控，筛掉明显已会的题 | 否（沿用已有） |
| 2 | 知识侧信号 | 算 `coverage(q)`，含概念清单→分层→定价三子步 | **是（核心）** |
| 3 | 跨题全局分配 | 子模贪心，MVP = 按 coverage 降序取前 B 道 | 是 |
| 4 | 执行 | 检索 → 给模型 → 答题 | 否 |

### 3.1 知识侧信号 `coverage(q)`（核心）

对每道进入预算池的题，算连续分数：

```
coverage(q) = Σ_{c ∈ G(q)}  p_c · ν_c
```

- **子步骤 A — 概念清单 K(q)**：双锚点（题干实体 + 答案实体）+ 四层召回（路径枢纽 / 不连通兜底 / 语料共现 PMI / 三阶段实体映射），原则**宁多勿漏**。
- **子步骤 B — 概念分层**：只对"没给但需要"的**缺口概念** `G(q) ⊆ K(q)` 定价。
- **子步骤 C — 定价**：边际增益 `mg_c = p_c · ν_c`
  - 稀有度 → 缺失概率 `p_c = σ((idf(c) − idf_median) / τ)`
  - 必要性 `ν_c`（是缺失概率的函数，**代入公式算，不数路径**）

### 3.2 跨题全局分配（子模贪心）

价值函数 `F(S) = Σ_{q∈S} coverage(q)`（单调子模）。在总预算 B 下最大化 F(S)，子模贪心可证 `1 − 1/e` 且与题序无关。

**MVP**：各题检索成本统一为 1，贪心退化为"按 `coverage(q)` 降序取前 B 道题"。**先跑通 MVP，再做完整子模贪心。**

## 4. 关键公式速查

设概念 `c` 的缺失概率为 `p_c`，掌握概率 `q_c = 1 − p_c`。

| 量 | 公式 |
| --- | --- |
| IDF 稀有度 | `idf(c) = log(N / (1 + df(c)))` |
| 缺失概率 | `p_c = σ((idf(c) − idf_median) / τ)`，`σ(x)=1/(1+e^{−x})` |
| 路径齐备概率 | `S(P) = Π_{c'∈P} q_{c'}` |
| 路径"除 c 外齐备" | `S_¬c(P) = Π_{c'∈P, c'≠c} q_{c'}` |
| 存在经过 c 且除 c 外齐备 | `P(E_I) = 1 − Π_{P∋c} (1 − S_¬c(P))` |
| 所有绕过 c 的路径都不齐备 | `α(c) = Π_{P∌c} (1 − S(P))` |
| 必要性 | `ν_c = P(E_I) · α(c)` |
| 概念边际增益 | `mg_c = p_c · ν_c` |
| 题目分数 | `coverage(q) = Σ_{c∈G(q)} p_c · ν_c` |

> ⚠️ `coverage` 是"答题前的估值信号"，**不是答对概率本身**。已有工作（TRIAGE）发现"覆盖度 ≠ 答对"；本文贡献是把 coverage 的**忠实边界**（什么条件下忠实、什么条件下失真）证明清楚。

## 5. 已定默认决策（直接照做）

- 主数据集：**MedQA**（USMLE 四选一，hard 子集 + full set）；辅助：**MedMCQA**。不用 MMLU / MMLU-Pro / PubMedQA 做主数据。
- 知识图谱：首选 **UMLS**（无 license 退回 **PrimeKG**）；语料：**PubMed 摘要**。
- 模型：开源通用 LLM（Llama-3、Qwen2.5 系列）。
- 预算口径：`B` = 最多允许"检索"的**题目数**，每道题检索成本统一为 **1**。
- 缺失概率校准：`τ = 1.0`（初始），后续在 `{0.5, 1.0, 2.0}` 网格搜索。
- **排除 AI + 医学影像**，只做医学 QA 文本题。
