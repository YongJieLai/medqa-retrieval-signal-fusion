## M0 — 环境与数据准备

**目标**：数据与外部资源就绪，可被后续所有里程碑复用。

**产出**
- [ ] MedQA（USMLE 四选一）：hard 子集（沿用 MedCoG 划分，Tang et al., 2025）+ full set
- [ ] MedMCQA（四选一，辅助）
- [ ] 知识图谱：UMLS（无 license 则退回 PrimeKG），实体 + 关系边
- [ ] 语料：PubMed 摘要（用于 IDF 频率与 PMI 共现）
- [ ] 依赖锁定：networkx、SapBERT（或等价医学 embedding）、LLM 推理环境

**验收**
- [ ] 数据集可加载为标准 schema：`{question_id, stem, options[4], answer}`
- [ ] KG 可查询实体与最短路径；语料可统计 `df(c)` 与共现 `N(q,c)`

## M1 — MVP 端到端最小闭环（优先级最高）

**目标**：先跑通一整条链路，哪怕信号层只做最简版。

**产出（按顺序）**
1. 概念清单构建：**只做层 1 路径枢纽 + 简单实体映射**（精确匹配即可）
2. 稀有度：`idf(c) = log(N/(1+df(c)))` → `p_c = σ((idf−idf_median)/τ)`，`τ=1.0`
3. 必要性：按公式 `ν_c = P(E_I)·α(c)`（路径齐备概率连乘）
4. 题目分数：`coverage(q) = Σ p_c·ν_c`
5. 分配：MVP = 按 `coverage(q)` 降序取前 B 道（检索成本统一为 1）
6. 执行：检索 → 给模型 → 答题，输出正确率

**验收**
- [ ] 一个数据集（MedQA）端到端跑通，输出每题的 `{闭卷/检索}` 决策与正确率
- [ ] 公式函数全部有单元测试（解析手算样例校验）
- [ ] 分象限（高/低缺失 × 高/低推理）能切出结果表

---

## M2 — 实验一：信号层评估

**目标**：验证我们的信号（coverage）比 entropy / confidence 更能挑出"检索前答不对、检索后能答对"的题。

**产出**
- [ ] 每题真实收益 = 检索后答对率 − 闭卷答对率，按价值排序（理想排序）
- [ ] 各方法（本文 / entropy / confidence / MedCoG）分别算分数、排序
- [ ] 秩相关（Kendall's τ / Spearman）对比各方法排序与真实排序的距离

**验收**
- [ ] 秩相关结果表 + 显著性检验
- [ ] 本文信号在秩相关上至少与 entropy / confidence 可比（并以分象限结果说明主战场在"高缺失×低推理"）

---

## M3 — 补全召回层 + 完整分配层

**目标**：把 MVP 升级为完整方法。

**产出**
- [ ] 概念召回补全：
  - 层 1 路径枢纽（求 K 条最短路径上的中间节点）
  - 层 2 不连通兜底（各自扩 N 跳取交集 + SapBERT 语义近邻）
  - 层 3 语料共现（PMI，卡 `N(q,c)≥2`，PMI 当必要性代理）
  - 三阶段实体映射（精确匹配 → embedding 阈值 0.85 → 兜底匹配）
- [ ] 概念分层：缺口概念 `G(q) ⊆ K(q)`（只对"没给但需要"定价）
- [ ] 分配层：完整子模贪心（每次选边际增益最大的"题 × 动作"）

**验收**
- [ ] 完整信号层 + 完整分配层，长尾/罕见病概念也能挂上图并定价
- [ ] 子模贪心与 MVP 排序结果可对比，单测覆盖

## M4 — 主实验 + 消融 + 四象限 + 跨模型稳定性

**目标**：跑完全部四个实验，产出论文级结果。

**产出**
- [ ] 实验二（三臂主实验）：Baseline / 融合 / 替换 × 挂载对象 {Adaptive-RAG, MedCoG, UAB}
- [ ] 实验三（消融）：信号层逐一摘除（概念清单 / 稀有度 / 必要性 / 门控）+ 分配层对比（子模贪心 vs 阈值截断 vs 随机）
- [ ] 实验四（模型无关性）：多 backbone（Llama-3、Qwen2.5 等）下 coverage 分数与秩相关稳定
- [ ] 全部结果按四象限切分输出

**验收**
- [ ] 主结论"融合 > 单独"有数据支撑（不要只比"替换 vs baseline"）
- [ ] 四象限结果验证"高缺失×低推理收益最大、高缺失×高推理被乘性吃掉"
- [ ] 结果全部落 `.csv` / 表格，原始日志留档，可重算

## M5 — 超参调优

**目标**：在完整方法上调超参，锁定最终配置。

**产出（按顺序）**
- [ ] `τ ∈ {0.5, 1.0, 2.0}` 网格搜索，以实验一秩相关最高者为准
- [ ] PMI 最低共现次数阈值调优
- [ ] 路径条数 K 调优

**验收**
- [ ] 每个超参都有消融/敏感性曲线，改动有实验一秩相关作为判据

## 交付物清单（与文档 §9 对应）

1. **信号层实现**：概念清单（双锚点 + 四层召回 + 三阶段实体映射）→ 概念分层 → 稀有度/必要性 → `coverage(q)`
2. **分配层实现**：子模贪心（先跑通"按 coverage 排序取 top"的 MVP）
3. **实验脚本**：四象限切分 + 四个实验的评测（秩相关、三臂正确率/效率、消融、跨模型稳定性）
4. **结果**：四个实验数值 + 四象限分象限结果，输出成表（`.csv` / 表格）
