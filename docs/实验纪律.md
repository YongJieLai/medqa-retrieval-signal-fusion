# 实验纪律

> 本文是跑实验方（跑实验的 agent / 研究者）必须遵守的规范。核心原则：**实验口径照文档执行，结果客观解读、不夸大。**

---

## 1. 总纲

1. 实验口径（数据集、baseline、指标、切分方式）以《技术交接文档》为准，**数据集 / baseline 的具体设置以 MedCoG 开源仓库为准**（复用其数据与评测协议）。
2. 每个实验都记录：**可复现配置**（种子、依赖、模型版本、数据子集）+ **原始日志** + **结果表**，缺一不可。
3. 结果解读**客观、不夸大**。凡是"预期内的劣势"要如实报告，不得选择性展示。

## 2. 四象限切分（所有实验都必须按它切）

把测试题按两个维度分四类，**每个实验都必须分象限出结果**：

| | 低推理难度（ε 低） | 高推理难度（ε 高） |
| --- | --- | --- |
| **高缺失（σ 高，罕见）** | **主战场**（罕见病简单题） | 收益被乘性吃掉（A2） |
| **低缺失（σ 低，常见）** | 都不需要检索 | 模型侧主战场 |

- 缺失 σ 高/低：用概念 IDF / 频率衡量（罕见病、罕见药 = 高缺失）。
- 推理难度 ε 高/低：用题目跳数（多跳 = 高推理）或模型侧信号衡量。

> **这是本文最关键的可证伪预测**：方法在"高缺失 × 低推理"象限收益最大，在"高缺失 × 高推理"象限被乘性吃掉。实验必须验证这两个象限的差异。

## 3. 实验口径（不得擅自更改）

1. **数据集**：主用 MedQA（USMLE 四选一，hard 子集 + full set），辅助 MedMCQA；确保有"罕见病 / 长尾"题目分布，否则四象限切不出来。不用 MMLU / MMLU-Pro / PubMedQA 做主数据。
2. **预算口径**：`B` = 最多允许"检索"的**题目数**（不是 token / 文档数），每道题检索成本统一为 **1**。
3. **缺失概率校准**：`τ = 1.0` 起步，后续 `{0.5, 1.0, 2.0}` 网格搜索，以实验一秩相关最高者为准。
4. **baseline 必须全覆盖**：entropy / confidence、MedCoG、KBM、Marina、QuCo-RAG、UAB。
5. **排除 AI + 医学影像**，只做医学 QA 文本题。

## 4. 主实验三臂（主叙事，务必三臂都跑）

| 臂 | 含义 | 说明 |
| --- | --- | --- |
| Baseline | 不加我们的信号 | 原始方法 |
| 融合 | 原方法信号 + 我们的信号 | **主叙事押这一臂** |
| 替换 | 把原方法信号替换成我们的信号 | 补充对照 |

- 挂载对象：Adaptive-RAG、MedCoG、UAB。
- **主结论是"融合 > 单独"**（对应定理 A2 的正交性：模型侧信号逼近推理失败 ε、我们的信号逼近知识缺口 σ，二者正交）。
- **不要只比"替换臂 vs baseline"**，那样会漏掉核心叙事。

## 5. 指标与统计口径

1. **信号层**（实验一）：秩相关（Kendall's τ / Spearman），比较各方法排序与真实收益排序的距离。
2. **主实验**（实验二）：正确率 + 效率（在预算 B 内答对的题数 / 每预算的收益）。
3. **消融**（实验三）：逐一摘除组件后的正确率/秩相关变化。
4. **跨模型**（实验四）：coverage 分数与秩相关在多个 backbone 上的稳定性。
5. 排名/相关性结论必须报告**统计显著性**（如需要，做 bootstrap / 显著性检验），不裸报一个数字下结论。

## 6. 结果记录与可追溯

1. 所有结果落成 `.csv` / 表格，原始推理日志、检索日志、模型输出**全部留档**。
2. 分象限结果单独出表，不允许只报"总体正确率"掩盖象限差异。
3. 结果文件与生成脚本同目录管理，脚本 → 结果一一对应，任意结果可重算。

## 7. 解读红线（防夸大）

1. `coverage` 是**估值信号**，不是答对概率——结果解读与图表标题不得把 coverage 当准确率。
2. 单独臂在"低缺失 × 高推理"上很可能**打不过模型侧**，这是**预期内，不是失败**——如实报告。
3. coverage 在"多路可绕"（或-题）上会**系统性高估**（缝合定理），这是已知局限，结果里遇到时要标注，不得隐藏。
4. 概念强相关时会失真（定理 A1*），必要时报告相关性影响。

## 8. 数据安全

1. **严禁在信号计算中使用答案字段**（答题前约束），数据泄漏是实验的致命错误。
2. 数据集 license（UMLS 是否可用）先确认；无 license 时**退回 PrimeKG**，不得越权使用。
3. 模型权重、数据、结果大文件不入库（见代码纪律 Git 部分）。

## 9. 实验自检清单

- [ ] 每个实验都按四象限切分出结果
- [ ] 主实验三臂齐全，主叙事押"融合 > 单独"
- [ ] baseline 全覆盖（entropy/confidence、MedCoG、KBM、Marina、QuCo-RAG、UAB）
- [ ] 信号层用秩相关评估，报告显著性
- [ ] 消融逐一摘除组件，分配层三对比（子模贪心 vs 阈值 vs 随机）
- [ ] 跨模型稳定性（Llama-3、Qwen2.5 等多 backbone）
- [ ] 结果落 csv/表格，原始日志留档，可重算
